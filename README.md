# Responsive E-Commerce Product Gallery (WE Lab 8)

A responsive e-commerce product gallery built using **CSS Grid** (`repeat(auto-fit, minmax(250px, 1fr))`) without explicit media queries, featuring smooth card elevation and image zoom hover transitions.

## Files Included
- `index.html` — Semantic HTML5 structure for the storefront header, product cards, and footer.
- `style.css` — CSS Grid auto-fit layout and hover animations.
- `README.md` — Project documentation.
